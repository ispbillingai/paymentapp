01

Available in this release

The service includes direct receipt ingestion, live intent matching, signed webhook delivery, claims, merchant API credentials and listener device controls. The developer sandbox adds isolated test accounts, test keys, idempotent intent creation, scenario simulation and an event inspector.

02

Planned channels

Provider API channels are planned. Card acceptance, hosted card checkout, gateway-held balances and automated payouts are not current capabilities. An upcoming label is not an availability date or a promise of provider approval.

03

Account features still to build

Email verification, self-service password recovery, multi-factor authentication, team invitations and granular roles need additional implementation. Do not represent the current account system as supporting these controls. Production access arrangements must reflect the actual features enabled.

04

Help prioritise

Share your country, provider, billing platform and the operational problem you need solved. Supply redacted receipt samples for parser work. Feature decisions and delivery dates will be confirmed separately; this roadmap is not a contractual commitment.
